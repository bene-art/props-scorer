# Security Policy

## Reporting a vulnerability

If you've found a security issue — leaked credential in this repo's history, vulnerable dependency, exploitable bug — **please don't open a public issue**.

Use GitHub's private vulnerability reporting: go to the [**Security** tab](https://github.com/bene-art/props-scorer/security/advisories/new) and click **Report a vulnerability**.

Solo maintainer — best-effort response within a week, no formal SLA.

## Supported versions

This is a stable snapshot of one slice of a larger private system. Only the latest commit on `main` is supported.
